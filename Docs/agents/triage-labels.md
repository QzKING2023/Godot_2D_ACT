# 分流标签

技能使用五种标准分流角色。本文件把这些角色映射到本仓库 Issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可以交给后台代理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，例如“应用 AFK 就绪标签”，使用本表中对应的标签字符串。

如果跟踪器的实际词汇发生变化，编辑“本仓库跟踪器中的标签”一列。
